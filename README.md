# Посмотри в окно

Проектная работа третьего спринта курса «Фронтенд-разработка» (Яндекс Практикум): CSS для готового приложения «Посмотри в окно» — видеоплеер с карточками видео из разных городов и формой поиска по городу и времени суток. HTML и скрипт получены в заготовке, в ходе работы дописан файл `styles/style.css`.

Репозиторий проекта: https://github.com/aMyrrh/posmotri-v-okno-ad

## Что сделано

- Лейаут на флексбоксе: центрирование страницы, колонки с видео и карточками, поисковая форма.
- Фиксированная высота списка карточек со скроллом, обрезка длинных заголовков (`text-overflow`) и описаний (`line-clamp`).
- Кастомные поле ввода и чекбоксы (`.visually-hidden`, псевдоэлемент `::after`, `:checked`), фокус через `:has(:focus-visible)`.
- Кнопки и карточки с состояниями `:hover`, `:active`, `:focus-visible`, выбранная карточка (`.content__card-link_current`).
- Позиционирование прелоадеров поверх видео и списка карточек.

## Структура

- `index.html` — страница
- `fonts/` — шрифты и `fonts.css`
- `scripts/script.js` — логика приложения
- `styles/style.css` — стили проекта
- `styles/preloader.css`, `styles/error.css` — стили прелоадера и сообщения об ошибке

## Запуск

Откройте `index.html` в браузере (данные подгружаются с внешнего источника).
